# Highlight Key Points

1. Identify the selected text or slide. If scope is unclear, ask before editing.
   Do not rewrite unrelated slides.
2. Convert the selected content into short, parallel bullet points. Preserve
   facts, numbers, qualifiers, citations, and the original language.
3. Keep the existing font, size, indentation, and surrounding layout. Highlight
   only important phrases, not entire paragraphs, using the deck's accessible
   blue accent; use `0F6CBD` only when it fits the background and template.
4. Keep emphasis understandable without color alone, for example through concise
   wording or existing bold styling. On dark backgrounds use a lighter
   theme-compatible accent if the default blue is not legible.
5. Inspect text fit, bullet hierarchy, contrast, and content fidelity. If the
   result does not fit, propose splitting or shortening it rather than silently
   shrinking the font or deleting meaning.
6. Report the edited scope and any unresolved issues.
